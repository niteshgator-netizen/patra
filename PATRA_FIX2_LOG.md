## SLA ACTIVATION — what Genius must click (in order)

1. On Render → Environment, set `PATRA_ADMIN_CONSOLE_ACTIONS=true` (needed for step 3's feature toggle; you can set it back to false afterwards).
2. Open `https://patrahq.com/super_admin` → Patra Accounts → your account (id 2).
3. In the Features list, find `sla` and click Enable (give a reason — it's audited).
4. Back in the app (patrahq.com/app), go to Settings → SLA (new sidebar item) → "Add SLA". Name it (e.g. "Cashout response"), set First Response = 5 minutes, Resolution = 30 minutes, save.
5. To apply it automatically to every new conversation in the FB inbox: Settings → Automation → Add rule → event "Conversation created" → condition "Inbox is <your FB inbox>" → action "Add SLA" → pick the policy → save.
6. Done — from the next conversation onward, the list cards and the conversation header show the countdown chip (green → amber → red). Existing conversations get a chip when the automation re-fires on them (or assign the SLA manually from the conversation).
